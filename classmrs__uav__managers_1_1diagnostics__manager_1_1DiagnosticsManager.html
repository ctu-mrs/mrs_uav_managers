Detailed Description

ROS2 composable node that aggregates UAV diagnostics from multiple subsystems.

Subscribes to HW API, control manager, estimation, battery, GNSS, magnetometer, and RC channels. Publishes unified diagnostics messages at configurable rates. Maintains a UAV state machine (DISARMED, ARMED, OFFBOARD, TAKEOFF, HOVER, etc.) and monitors system health including CPU, RAM, WiFi signal strength, and sensor status.
